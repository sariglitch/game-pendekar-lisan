Cara Bagikan ke Siswa

Aplikasi ini berbentuk Single-File Web App gratis dan ringan. Anda dapat membagikannya kepada para siswa dengan beberapa cara mudah tanpa biaya hosting:

1 GitHub Pages (Gratis & Paling Direkomendasikan)

Simpan file index.html di repository GitHub, lalu aktifkan GitHub Pages di menu Settings menu.

Repository Settings ➡️ Pages ➡️ Source: Deploy from branch 'main'

2 Netlify / Vercel (Drag and Drop File)

Cukup registrasi akun gratis di Netlify/Vercel, lalu tarik & lepas (drag-and-drop) folder berisi file index.html ini untuk langsung mendapatkan tautan web instant.

3 Integrasi Database Firebase / Supabase (Pengembangan Lanjutan)

Aplikasi ini menyimpan data hasil di browser lokal. Jika ingin menyimpan skor siswa dari jarak jauh di cloud server pengajar, tinggal hubungkan API Firestore / Supabase pada fungsi saveStudentScore() dalam script.
